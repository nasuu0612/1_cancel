# ハッカソンで早起きしたくなるような<br>塗り絵アプリを作成しました

大学生に早起きは難しい。<br><br>
そのため、早起きしたくなるようなアプリを作成することにしました。<br><br>
このアプリを使うことで...<br><br>

- 塗るために早く起きる！
- 早起き状況を可視化できる！
- 毎日早起きしたくなる！
<br>
毎日早起きすることで達成感が味わえます！！<br><br>
